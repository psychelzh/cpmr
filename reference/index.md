# Package index

## Native CPM API

Primary entry points for defining CPM analyses and running them.

- [`spec()`](https://psychelzh.github.io/cpmr/reference/spec.md)
  [`cpm()`](https://psychelzh.github.io/cpmr/reference/spec.md) : Define
  a CPM specification

## Stage Helpers

Helper constructors for staged CPM specifications.

- [`cpm_selection_cor()`](https://psychelzh.github.io/cpmr/reference/cpm_selection_cor.md)
  : Define CPM correlation-based edge-selection settings
- [`cpm_construction_strength()`](https://psychelzh.github.io/cpmr/reference/cpm_construction_strength.md)
  : Define CPM strength-construction settings
- [`cpm_model_lm()`](https://psychelzh.github.io/cpmr/reference/cpm_model_lm.md)
  : Define the outcome model used after CPM feature construction

## Result Objects

Result objects and summaries returned by

- [`cpm_object`](https://psychelzh.github.io/cpmr/reference/cpm_object.md)
  : cpm object
